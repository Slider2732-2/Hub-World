An Arduino project with the intention of linking several satellite units to a main central hub. <br>
It is broadly similar to the way that the popular Radica Cube World operated from approx 20 years ago. <br>
The main Hub contains an Arduino Nano V3, SSD1306 screen, 2 LED's (1 red, 1 green) and a small speaker. <br>
Satellite units contain an Arduino Nano V3 and SSD1306 screen. <br>

Connections between the circuits are with 4 magnets. <br>
Those magnets connect to Vcc, Gnd, TX, RX on the Hub and Vcc, Gnd, RX, TX on the satellites. <br>
<br><br>
The above Arduino code is merely the very first test sketch and much more will be added to this repository in time. <br> 
See the Slider2732_ YouTube channel for more information and demo.
